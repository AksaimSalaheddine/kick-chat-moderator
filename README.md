# Kick Chat Moderator

A Python-based chat moderation bot designed to detect and filter inappropriate messages in Kick chat.

## 🚀 Project Goal

The goal of this project is to build a practical Python moderation bot while learning:

- Python
- Object-Oriented Programming
- Git & GitHub
- Testing
- Data structures
- APIs
- Databases
- Automation
- Deployment
